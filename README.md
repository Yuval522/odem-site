# odem Kitchens – odemdesign.co.il

Marketing site for **odem Kitchens (מטבחי אודם)**, a custom kitchen and joinery workshop in Moshav Givolim, Israel.

- Static site, generated by `build.mjs` (Node, no framework) into `dist/`
- Hosting: Cloudflare Pages (project `odem-kitchens`), domain `odemdesign.co.il`
- Self-hosted fonts, no third-party trackers; accessibility menu + cookie notice in `static/widgets.js`
- SEO: JSON-LD (LocalBusiness, FAQPage, Service), `sitemap.xml`, `robots.txt`, `llms.txt`

## Build

```bash
node build.mjs        # writes dist/
```

Deploy: every push to `main` is built and published automatically by Cloudflare Pages (build command `node build.mjs`, output directory `dist`).
